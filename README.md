# ⌨️ TYPE.IO

**TYPE.IO** is a fast-paced typing and spelling game where your goal is to type the displayed words **as quickly and accurately as possible**.

Build combos, earn points, improve your typing speed, and try to beat your high score!

## 🎮 How to Play

1. Open **TYPE.IO**.
2. Choose a difficulty from the menu.
3. A word will appear on the screen.
4. Type the word exactly as shown.
5. Submit the word by completing it.
6. Type as quickly as possible before the timer runs out.
7. Keep getting words correct to build your combo.
8. Try to get the highest score!

## 🔥 Difficulty Levels

* 🟢 **Easy** — Short words and more time.
* 🔵 **Normal** — A balanced challenge.
* 🟠 **Hard** — Longer words and less time.
* 🔴 **Insane** — Very difficult words with extremely limited time.

The game becomes faster as you progress.

## 🏆 Scoring

Your score depends on:

* ⚡ Typing speed
* 🎯 Accuracy
* 🔥 Combo streak
* 💎 Difficulty bonus

Faster typing and longer combos mean more points.

## 🎮 Controls

**Type:** Type the word displayed on screen.

**ESC:** End the current game.

## 🚀 Running TYPE.IO

TYPE.IO is built as a single HTML file, so it can run directly in your browser.

It can also be hosted on:

* GitHub Pages
* Netlify
* LiveCodes
* Any normal web server
